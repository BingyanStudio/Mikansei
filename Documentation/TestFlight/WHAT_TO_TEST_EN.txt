# Mikansei 0.7.1 Beta Test Notes

## TestFlight update text

Native Mikansei 0.7.1 adds a focus Live Activity to the Lock Screen and Dynamic Island. The Lock Screen highlights the focus subject and a large timer. Use the activity to pause or resume, or finish and save a focus session. After dismissing the activity manually, restore it from the app. The existing deadline Live Activity remains independent. Focus supports both countdown and count-up; please check countdown expiry and the Live Activity's eight-hour system limit.

## What to test

- Start a focus session with a subject. Check the subject and large timer on the Lock Screen and Dynamic Island. A countdown should show time remaining; count-up should show elapsed time. Dynamic Island checks require a supported device.
- Pause and resume from the Lock Screen or Dynamic Island. Confirm the app opens to process the action and the timer remains continuous. Choose “Finish and Save” and confirm that the app saves one focus record with the correct subject, duration, and end state.
- Dismiss the focus Live Activity manually and confirm the local timer continues. Return to the app and use “Show Again” to restore it. If Live Activities are disabled in system settings, confirm local focus sessions and history remain available.
- Create both a deadline Live Activity and a focus Live Activity. Confirm each is displayed independently; ending or dismissing the focus activity should leave the deadline activity intact.
- Try both countdown and count-up, including pause, resume, and finish. When a countdown expires, check the activity message and open the app to review the record. Do not expect an automatic alarm or rest cycle.
- Note the Live Activity's eight-hour system limit. After the activity expires, it should direct the user to open the app; the app continues to manage the local timer and saved history. There is no need to wait eight hours for testing; report this state if encountered naturally.
