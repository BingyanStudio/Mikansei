Mikansei is a native SwiftUI task, schedule, and notes app for iPhone and iPad. Local features work offline without an account. Optional email-code cloud sign-in is shared with Mikanseta; the app merges local content with that account’s cloud archive only after the user confirms.

Please begin the review without signing in and review local features:
1. On first launch, the app may request calendar access; you may decline. No calendar sources are selected initially. A built-in “使用说明” (User Guide) note may appear on first install.
2. Create a task: open “待办” (Tasks), tap +, enter a title, and tap “保存” (Save).
3. Checklist: open a task, add a step under “Checklist · 逐项勾选,” save, and tap a step to toggle it. Tap the circle beside the task title to complete or reopen it.
4. Create a note: open “笔记” (Notes), tap +, enter a title and body, and tap “完成” (Done).
5. JSON backup: tap the upper-left gear, then “我的” (Settings) → “数据与备份” (Data and Backup) → “导出 JSON 备份” (Export JSON Backup).
6. Calendar import is optional. Open “日历自动导入” (Automatic Calendar Import), grant access if desired, select a test calendar, and tap “立即同步” (Sync Now). Only selected sources are imported.
7. Widgets, notifications, alarms, and Live Activities are optional system integrations. Declining permissions does not block local tasks or notes. AlarmKit requires iOS 26 or later; the app minimum is iOS 17.
8. Privacy and support links are under “我的” → “隐私与支持.”
