# Mikansei 测试支持

本页适用于原生 Mikansei iOS TestFlight 测试版；邮箱云账号与 Mikanseta 共用服务。

**反馈邮箱：kikuchiheinr@qq.com**

## 开始使用

- 底部“待办 / 日程 / 笔记”切换内容；右上角“＋”新建事项或笔记。
- “日程”页的“规划”入口安排执行日期或时段。
- 左上角齿轮打开“我的”；新安装后，“笔记”内有“使用说明”。
- 不登录也可离线使用。本机数据在用户确认登录前不会上传。
- 邮箱验证码云账号和 iCloud Drive 文件夹同步彼此独立，均为可选功能。邮箱账号也用于 Mikanseta；不要登录他人账号。

## 邮箱云账号

在“我的”→“Mikansei · Mikanseta 云账号”输入自己可访问的邮箱，请求一次性验证码。验证码是 6–10 位数字；此服务不使用密码。首次请求验证码时，新邮箱可自动创建账号；完成验证码验证后才能登录。首次登录前，App 会要求你确认本机内容将与该账号现有云归档合并。请只使用属于自己的账号。

云账号复用现有 Supabase Auth 和共享归档表。本轮尚未发送真实验证码、完成登录或在线同步验收。如果设置页显示云服务暂不可用，或验证码无法发送，请先继续离线使用并邮件反馈，不要反复尝试私人主账号。

“退出登录”会保留本机和服务端数据。删除账号会移除 Mikansei 与 Mikanseta 共用的服务端账号和归档；其他设备无法正常刷新登录或继续写入该归档，但已有登录令牌可能在到期前仍有效。其他设备的本地副本不会自动清除。`mikansei_delete_account` RPC 已于 2026-10-29 部署并核对权限；真实删除流程尚未端到端验收。若 App 内操作失败，请联系支持邮箱提出删除请求。

## 常见问题

### 日历没有导入

在设置中打开“日历自动导入”，确认系统权限，勾选希望导入的日历，再点“立即同步”。首次使用默认不勾选来源。拒绝日历权限不会阻止本地清单和笔记使用。

### 云账号没有验证码

确认邮箱拼写正确并检查垃圾邮件。验证码由共享账号服务发送；本轮尚未真实验证邮件投递。如仍无邮件，请继续离线使用并反馈，不要尝试他人账号。

### 两台设备上的云数据没有更新

确认两台设备登录的是同一邮箱、网络可用且云服务已启用。外观与日历来源仍按各设备设置。云同步本轮未完成真实设备验收；请记录操作时间和步骤反馈，不要发送私人内容。

### 小组件没有内容

安装后先打开 App，添加一条事项，再长按主屏幕添加 Mikansei 小组件。设置中若提示共享数据不可用，请反馈提示文字；这可能涉及测试构建的签名配置。

### 没有显示实时活动或系统闹钟

设置 → “锁屏与灵动岛 · 实时活动”中开启“自动显示今日 DDL”，并确认有符合条件的未完成事项。AlarmKit 需要 iOS 26 或更新版本及独立授权。

### 换版本或换手机前如何备份

设置 → “数据与备份” → “导出 JSON 备份”，把文件保存在安全位置。新版本中用“导入 JSON 备份”合并。不同 Bundle ID 的 App 不会自动共享原来的本机数据。

### 如何停止 iCloud Drive 文件夹同步

设置 → “iCloud Drive · 跨设备同步” → “停止本机同步”。此操作保留本机数据和同步文件夹中的文件。退出邮箱云账号也会保留本机和服务端数据。

### 读取本机数据失败

如果 App 提示“本地数据读取失败”，请保留 App，不要先卸载。向反馈邮箱描述情况；开发者无法从云端恢复未上传的本机数据。
