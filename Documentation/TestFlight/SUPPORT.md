# Mikansei 测试支持

本页适用于原生 Mikansei iOS TestFlight 测试版，不是 Mikanseta。

**反馈邮箱：kikuchiheinr@qq.com**

## 开始使用

- 底部“待办 / 日程 / 笔记”切换内容。
- 右上角“＋”新建事项或笔记；事项可以包含 Checklist、截止日期和提醒。
- “日程”页的“规划”入口安排执行日期或时段。
- 左上角齿轮打开设置；新安装后，“笔记”内有“使用说明”。
- 本版本不需要注册或登录。日历、提醒和文件夹同步可以按需要授权或配置。

## 反馈时提供

1. 设置中显示的 App 版本及构建号。
2. 设备型号和 iOS 版本。
3. 操作步骤、预期结果、实际结果。
4. 如有帮助，可附截图或 TestFlight 反馈。分享前检查其中是否包含不愿公开的事项。

也可使用 [GitHub Issues](https://github.com/KikuchiHeinrich/Mikansei/issues) 反馈，但 Issue 默认公开，私人信息请通过邮件联系。

## 常见问题

### 日历没有导入

在设置中打开“日历自动导入”，确认系统权限，勾选希望导入的日历，再点“立即同步”。首次使用默认不勾选来源。拒绝日历权限不会阻止本地清单和笔记使用。

### 小组件没有内容

安装后先打开 App 一次，添加一条事项，再长按主屏幕添加 Mikansei 小组件。设置中若提示共享数据不可用，请反馈原文；这可能涉及测试构建的签名配置。

### 没有显示实时活动

设置 → “锁屏与灵动岛 · 实时活动”中开启“自动显示今日 DDL”，并确认有符合条件的未完成事项；必要时点“重新显示 / 更新”。显示位置和灵动岛支持情况取决于设备和系统。

### 没有系统闹钟选项

系统闹钟使用 iOS 26 的 AlarmKit，需要相应系统版本和独立权限。较早系统仍可使用支持的通知提醒。

### 换版本或换手机前如何备份

设置 → “数据与备份” → “导出 JSON 备份”，把文件保存在安全位置。新版本中用“导入 JSON 备份”合并。不同 Bundle ID 的 App 不会自动共享原来的本机数据。

### 如何停止同步

设置 → “iCloud Drive · 跨设备同步” → “停止本机同步”。此操作保留本机数据和同步文件夹中的文件。

### 读取数据失败

如果 App 提示“本地数据读取失败”，请保留 App，不要先卸载。向反馈邮箱描述情况；开发者无法从自己的服务器恢复你的本机数据。
