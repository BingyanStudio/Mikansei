# 专注计时

专注计时与清单任务分开保存。开始一段计时前需要填写专注主题；可选关联一项未完成任务。倒计时按设定时长运行，正计时不设时长。计时可以暂停、继续或结束，历史会记录主题、持续时间、结束时间和完成或提前结束状态。

## 计时与记录

- 计时状态使用开始时间、累计专注秒数和暂停状态保存。重新打开 App 后，会根据时间戳恢复运行中的计时；暂停期间不累计时间。已经到期的倒计时会在 App 恢复运行时补记。
- 数据保存在独立的本机 `pomodoro.json` 文件中，不并入任务数据，也不纳入清单备份或云端清单同步。
- “今日记录”按专注记录的结束日期统计。跨过午夜结束的一段计时会记入结束当天；正在进行的计时尚未结束，不计入该数字。完成次数是累计完成次数。
- 倒计时到时后，App 会在下一次活动刷新时结束并记录本段专注。当前没有自动休息周期，也不会为专注计时安排闹钟或到时提醒。

## 各平台的显示方式

| 平台 | 计时入口与显示 |
| --- | --- |
| Mikansei macOS、Mikanseta macOS 和 Windows | 应用可打开独立的浮动计时窗口；计时器在应用主窗口之外显示。 |
| Mikansei iOS、Mikanseta iOS | 使用 iOS 主屏小组件的系统网格尺寸；小、中、大尺寸适配显示主题和计时，大尺寸还显示今日记录与累计完成次数。 |
| Mikanseta Android（API 24+） | 使用 Android 启动器提供的主屏小组件尺寸显示计时状态。正计时使用系统 Chronometer 实时计数；倒计时只有在设备已有精确闹钟访问权限时使用实时 Chronometer，否则以已保存的时间戳计算并将剩余时间限制在零以上，显示截止 / 刷新提示。 |

iOS 和 Android 的小组件控制链接会打开 App，再按当前计时编号处理暂停、继续或结束；已经被替换或结束的旧链接会被忽略。小组件负责显示共享的当前状态，不保存完整历史。Android 使用启动器小组件，不会在其他 App 前显示浮动窗口；桌面浮窗则是独立窗口，不是主屏小组件。
